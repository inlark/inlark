Inter Variable 4.1, from the [Inter project](https://rsms.me/inter/).

`InterVariable.woff2` is bundled locally for consistent, offline typography. It is
licensed under the SIL Open Font License in `OFL.txt`. The desktop renderer also
ships that license from `public/licenses/Inter-OFL.txt`.

The shared `Wordmark` component uses outlined Hanken Grotesk lettering from the selected
**02 Soft** design. Its license is in `HankenGrotesk-OFL.txt` and is also shipped in
the desktop renderer's `public/licenses/` directory. No Hanken Grotesk font file is
needed to render the wordmark.
